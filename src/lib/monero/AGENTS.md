# Monero

- Monero runs through Seeds' own Monero server (monerod + monero-wallet-rpc behind an HTTPS proxy, Bearer MONERO_WALLET_RPC_TOKEN; MONERO_WALLET_RPC_URL). Watch wallets hold the VIEW key only (created once by the scheduled job /api/public/jobs/monero, which unlocks the pocket key just to derive it); a send loads the spend key into a throwaway `seeds-send-*` wallet, builds with do_not_relay, checks address/amount/fee cap (rules.ts previewProblem, tested), records the txid, then relays. wallet-rpc opens one wallet at a time, so every call holds the monero_take_lease lease and closes the wallet after. Display balances come from monero_wallets (unlocked = balance, locked = "arriving"); sends read live. Deposits stay closed (moneroBlocker) until the server is connected and the member's watch wallet is ready. Why: Monero can't be read from outside without the view key, and no deposit may be one-way.
