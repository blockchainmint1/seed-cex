# Account
- Balances page lists every supported coin (main rows from deposit-options, "Re-link to add" for networks the link lacks) plus Ethereum/Base ERC-20s from src/lib/account/erc-tokens.ts (tested: swap-list tokens always, other held tokens via Alchemy labelled "not checked by Seeds", junk hidden), 25 per page. Native Stellar/TON/Sui rows use that same catalog; their deposit/send gate is ed-send-rules.ts. Unknown token rows remain display only. Why: one coin catalog avoids duplicate rows or actions for unavailable routes.
- A row's Swap link opens /swap already filled in on the pair that coin can actually do — sell what you hold to TSD, otherwise buy it with TSD — from src/lib/account/swap-link.ts (pure, tested); a row with no planned pair keeps the plain Swap page. Why: the link must land on the route the member meant, never an empty form.
