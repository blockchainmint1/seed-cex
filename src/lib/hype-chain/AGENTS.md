# One-tap HYPE swaps (any coin / TSD <-> ETH <-> HYPE)

- src/lib/hype-chain/: rules.ts (pure, tested: hopFor, ethToHandOn, chainMinimum), hype-chain.server.ts (quote, request, hype_chains stage machine), hype-chain.functions.ts. planSwap names kind "hype_chain" for every HYPE pair except ETH (plain Relay): TSD uses the TSD route, other coins THORChain/Maya. Why: members want one click, and every hop must still be an existing, audited send.
- Order: server quote ≤1% worse than shown → set-asides → reserve_hype_chain (one open per member) → ONE Telegram Approve (purpose hype_chain, spent once) → ETH baseline noted once (write-once) → step 1 → step 2 hands on only ethToHandOn (arrived ETH, never prior ETH, less step 2's fee) and only when a fresh price clears the agreed minimum, else kept_mid. Steps are tagged with the chain at insert (swap_sends.parent_id via _route_id, tsd_routes.parent_id via reserve_tsd_route _parent_id, relay_swaps.parent_id via reserve_relay_leg, which inserts already approved by the chain's tap) and adopted, never re-sent. Child rows are hidden from standalone My swaps lists. Testers only (relayBlocker). Why: one tap must never authorise more than the agreed swap, and a crash must never pay twice.
- to_ton_usdt (TSD/coin -> ETH -> TON -> USD₮ on TON): same chain plus step 3 on STON.fi. TON baseline noted once before the Relay step (ton_baseline_nano, write-once, reserve_relay_leg refuses without it); min_out guards the Relay step in TON, final_min (fixed) the last step in USD₮; step 3 hands on only tonToHandOn (arrived TON, never prior TON, less 0.265 TON fees) via startTonToUsdt with the chain as parent (ton_swaps.parent_id, checked by reserve_ton_swap, signed minimum ≥ final_min), adopted never re-sent; a stop leaves TON in the pocket (kept_mid). Why: every swap is one tap (Bobby, Nov 25), and the last hop must obey the same agreed minimum and never spend the member's own coins.
- Every one-tap swap that stops (kept_mid/failed) sends one Telegram alert to the member and one to every admin from step()'s go(); temporary price/balance read failures before step 3 retry for 30 min instead of stopping. Why: Bobby wants to know whenever a swap dies, and a blip in a price feed must not kill a swap.
- Any background swap that stops (one-tap chain, TSD route, Relay, two-step, pool swap, STON.fi unknown, THORChain/Maya refund) alerts once via src/lib/swap/stop-alert.server.ts: member + every admin; steps of a bigger swap stay quiet (parent alerts). Why: Bobby wants to hear about every swap that dies.
