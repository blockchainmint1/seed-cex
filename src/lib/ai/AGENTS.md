# Seeds AI
- Seeds AI lives in src/lib/ai/: plan.ts/theories.ts (pure engine shared by browser tester and daily server check; tested), lock-rules.ts + catalog.ts (only aiBuyable coins: THORChain route Seeds signs, or a "SEEDS:<pair>" EVM-leg TSD market), ai.server.ts (daily check, unique per plan+day so re-runs never resend), ai.functions.ts; prices download inside Postgres (ai_sync_request/ai_sync_ingest via /api/public/jobs/ai-daily schedules). ai_settings.execution_enabled stays false until buying is built and audited. Why: the message a member gets must match the plan they tested, and no coin is offered that Seeds can't actually buy.
- "Find my playbook" (src/lib/ai/playbook.ts, pure, tested) ranks rule combinations only on the older part of the history and uses the newest slice purely to report held-up/faded; the AI write-up (playbook.functions.ts, signed-in, daily cap via ai_playbook_notes) only explains numbers the engine produced. Why: picking on the whole history is curve-fitting, and an LLM must never invent returns.
