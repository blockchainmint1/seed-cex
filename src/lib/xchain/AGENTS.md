- Cross-chain swaps (THORChain + Maya) live in src/lib/xchain/: assets.ts (registry of every live pool except protocol-native tokens; per-network address rules in SWAP_CHAINS; memo shortcodes are per protocol and added only after a live quote proves them), safety.ts (pure memo/limit/vault rules, tested), router.server.ts (public-node reads). A route is send-ready only when memoSafe, limitOk and a 2-independent-server vault (and EVM router) check pass; /swap is read-only and never returns vault addresses. Why: a wrong memo or vault is an unrecoverable loss, and the same shortcode means different coins on THORChain and Maya.
