# PulseChain

- Seeds-signed PulseChain withdrawals (PLS, pHEX) live in src/lib/pulse/: withdraw-rules.ts (pure caps, hold, destination and fee rules; tested), withdraw.server.ts (request → reserve_pocket_withdrawal hold → scheduled /api/public/jobs/pulse-withdrawals claims due rows via claim_pocket_withdrawal, re-checks the same active instant-access link, stores the hash before broadcast, never re-signs). It is the only path where Seeds sends member coins to an outside address; API keys can't reach it. HEX on Ethereum is "HEX", HEX on PulseChain is "pHEX" (separate legs/markets); their prices come from CoinGecko/DexScreener in cmc.server.ts, never CMC by symbol. Why: HME Wallet can't send on PulseChain, so without this a PulseChain deposit would be one-way, and the two HEX coins differ in price several-fold.
- Withdrawal dollar caps and the hold come from the member's level (src/lib/withdraw-limits.ts pure + tested, withdraw-limits.server.ts reads levels/history/overrides; edited in /admin/settings via save_withdrawal_tiers / set_withdrawal_override, which check admin, refuse self-changes and log to withdrawal_limit_events). Missing levels fail closed; a paused member is blocked at request and again at send. Why: new members start low and earn higher limits from history, and every change is accountable.
