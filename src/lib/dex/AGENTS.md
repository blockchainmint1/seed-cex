# Single-network pools (Uniswap, PancakeSwap, PulseX)

- src/lib/dex/: venues.ts (pool registry + member warnings, pure, tested), abi.ts (hand-rolled calldata, tested), quote.server.ts (one Multicall3 eth_call per quote, read-only), market.server.ts (DexScreener search/market facts only — never the swap price), dex.functions.ts. Every router/quoter address is checked on-chain (factory/wrapped-coin answer + selector present in bytecode) before it is added. Why: a wrong router is an unrecoverable loss, and prices must come from the pools themselves.
- Members may pick any coin; risk is shown (sell-back check, pool size, age, price impact, hidden-tax disclaimer), never used to block. Only Uniswap v2/v3, PancakeSwap v2/v3 and PulseX v1/v2 pools count (v4 is skipped). Why: Bobby wants open choice; Seeds can only trade through pools it calls directly.
- Swaps live in swap-rules.ts (pure, tested: minimums, calldata, exact approvals, receipts, gates) and swap.server.ts (resumable dex_swaps stage machine, claimed per step, advanced by the tsd-routes minute job and the Swap page). Every swap: server re-quote ≤1% worse than shown → reserve_dex_swap (caps, one open swap per network) → Telegram Approve (send_approvals purpose dex_swap, spent once) → approve exactly the amount → fresh quote must clear the agreed minimum → eth_call test run → hash stored before broadcast; the recipient is always the pocket the coins came from. Why: no tap, no move; a refused or mispriced swap costs at most a network fee, and a swap can never pay an outside address.
- TSD on the Ethereum list is the TSD_DEX stand-in, never sent to a chain: buys run an ordinary TSD→USDC route first (pool chosen after the bridge pays, stops at >2% drift keeping the USDC), sells start a USDC→TSD route with the USDC the receipt shows. Those routes are hidden from listTsdRoutes and shown inside the token swap. Why: one TSD issuer, and a token swap is one row to the member.
